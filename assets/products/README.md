# Product photos

Drop product photos here and they appear in the photo box beside each product.

Name each file after the product's ASIN (the 10-character code in the Amazon link),
for example `B08HV3MPFD.jpg`, or after the product name in lowercase with dashes,
for example `phomemo-bluetooth-label-maker.jpg`. jpg, png and webp all work.

A square photo on a white background looks best. The site resizes it automatically.
Only use photos you're allowed to use: your own, or images from Amazon's Creators API.
